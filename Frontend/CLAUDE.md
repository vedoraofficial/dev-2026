# Frontend instructions

- Work only inside `Frontend/`. Never modify `Backend/`.
- Follow `docs/PROJECT-GUIDE.md` (folder structure + rules) for every change.
- Stack: Vite, React, TypeScript, Tailwind v4, shadcn/ui. Add UI primitives with `npx shadcn@latest add <name>`.
- Before finishing: `npm run lint && npm run typecheck && npm run format:check`.
